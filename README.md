# Website-Personal
Aplikasi Distribusi Pakan Ayam adalah sistem berbasis web yang mengelola stok, barang masuk dan keluar, serta jadwal pengiriman. Dengan fitur verifikasi dan pembuatan surat jalan, aplikasi membantu Kepala Logistik, Admin Gudang, dan Supir bekerja lebih cepat, akurat, dan efisien dalam proses distribusi.
